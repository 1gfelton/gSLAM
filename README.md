# gSLAM
A simple C++ implementation of EKF-SLAM and FastSLAM based on the tutorial from Durrant-Whyte and Bailey[1] and the model from Thrun et al.[2]

[1] - [Simultaneous localization and mapping: part I](https://ieeexplore.ieee.org/document/1638022/)
[2] - [Probabilistic Robotics](https://robots.stanford.edu/probabilistic-robotics/)
